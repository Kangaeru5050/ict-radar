# ICT RADAR

学校ICTの「今」と「基本」をつなぐ情報・学習サイト。

**知らないことに、出会える。今日のICTから、ひとつずつ。**

## 初期版
- 今日のICT：今知っておきたい変化への入口
- 今日のクイズ：1問から「知らなかった」に気づく
- こんなときどうする？：用語ではなく場面から探す
- もっと知りたい：基礎・一次情報へ進む

ICT支援員だけでなく、教員、管理職、教育委員会、学校ICTに関わる企業担当者までを想定しています。

## 編集方針
制度・法律・セキュリティ等は、ニュース記事だけで確定情報とせず一次情報へ接続します。自動収集した情報は、確認状態が分かる設計を目指します。
